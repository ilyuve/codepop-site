01配置 MCP 接入

选择你的 AI 工具，复制配置即可接入 CodePop

1

打开 Trae Settings

进入 Settings → MCP → Add Server

2

粘贴配置

{
  "mcpServers": {
    "codepop": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-sse@latest",
        "http://localhost:8080/mcp/sse"
      ]
    }
  }
}
3

重启 Trae

配置生效后，在对话中直接提问代码相关问题

1

编辑配置文件

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json

2

粘贴配置

{
  "mcpServers": {
    "codepop": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-sse@latest",
        "http://localhost:8080/mcp/sse"
      ]
    }
  }
}
3

重启 Claude Code

完全退出后重新启动，MCP 工具自动加载

1

打开 Cursor Settings

进入 Settings → MCP → Add Server

2

选择 SSE 类型并填写 URL

Server Type: SSE
URL: http://localhost:8080/mcp/sse
3

保存并测试

点击 Save，Cursor 会自动验证连接。成功后即可使用。

接入后可用的工具

codepop_search
混合代码搜索（向量 + 符号 + BM25 + 调用图）
codepop_repos
列出所有已索引的代码仓库
codepop_symbols
查看指定文件的符号列表
